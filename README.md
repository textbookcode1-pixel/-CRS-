# CRS 웹툰 번역·현지화 품질평가 연구

**Content Readiness Score (CRS)**

한국 웹툰의 다국어 번역 및 현지화 품질을 객관적이고 체계적으로 평가하기 위한 연구 프로젝트입니다.

## 연구 개요

- **연구명:** CRS 기반 웹툰 번역·현지화 품질평가
- **평가 대상:** 한국어 원본 및 일본어·프랑스어·인도네시아어·영어 번역본
- **평가 언어쌍:** ko-ja, ko-fr, ko-id, ko-en
- **핵심 평가 지표:** Content Readiness Score (CRS)
- **문화적 평가 요소:** Cultural Equalizer (CEQ)
- **연구 목적:** 웹툰 번역·현지화 품질의 객관적 평가 및 연재 적합성 판단

## 연구 방법

1. 국가별 문화 특성을 반영한 CEQ 프로파일 구축
2. 웹툰 원본과 번역본의 다차원 품질평가
3. CRS 점수 산출 및 품질등급 판정
4. 평가 근거와 오류 유형 및 개선 권고 도출

## 연구 목표

표준화된 평가 기준과 문화적 맥락을 기반으로 웹툰 번역·현지화의 품질을 정량적으로 평가하고, 평가 결과의 객관성과 재현성을 검증하는 것을 목표로 합니다.
